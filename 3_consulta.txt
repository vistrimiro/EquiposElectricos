Cómo se declara una variable compleja dentro de una clase en c++?

La variable “compleja” que buscas en C++ —una con **parte real** y **parte imaginaria**— se declara usando el tipo estándar **`std::complex<T>`**, que forma parte de la librería `<complex>`.

La idea central:  
> Un número complejo en C++ se representa como `std::complex<double>` (o `float`, `long double`).

---

### 🧩 Declaración dentro de una clase

```cpp
#include <complex>

class Generador {
private:
    std::complex<double> Z;   // número complejo: parte real + parte imaginaria
public:
    Generador() : Z(0.0, 0.0) {}   // inicialización real=0, imag=0
};
```

---

### 🔧 Asignación y uso

```cpp
Generador G1;
G1.Z = std::complex<double>(5.0, 2.0);   // Z = 5 + j2
```

También puedes modificar cada parte:

```cpp
G1.Z.real(10.0);
G1.Z.imag(3.5);
```

Y leerlas:

```cpp
double r = G1.Z.real();
double i = G1.Z.imag();
```

---

### 📐 Operaciones matemáticas

`std::complex` soporta suma, resta, multiplicación, división, magnitud, fase, etc.

```cpp
std::complex<double> A(3.0, 4.0);
std::complex<double> B(1.0, -2.0);

auto C = A + B;     // suma
auto D = A * B;     // producto
double mag = std::abs(A);   // magnitud
double ang = std::arg(A);   // ángulo
```

---

### 🎯 Integración con tu clase `Generador`

Si quieres que tu generador tenga una impedancia compleja, simplemente añade:

```cpp
#include <complex>

class Generador {
private:
    std::complex<double> Z;   // impedancia compleja
public:
    void setImpedancia(double real, double imag) {
        Z = std::complex<double>(real, imag);
    }

    std::complex<double> getImpedancia() {
        return Z;
    }
};
```
