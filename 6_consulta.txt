En C++ y winapi, Cómo se extraen los carácteres de una cadena wchar_t? Por ejemplo tengo una cadena varaux[20] = L"1,2,3" y deseo extraer los numeros separados por coma, que la conforma.

La forma de **extraer caracteres o números de una cadena `wchar_t` en WinAPI/C++** depende de lo que quieras hacer exactamente, pero te doy las tres técnicas más útiles y prácticas, ordenadas de más simple a más robusta.

---

## 🎯 **Respuesta corta**
Si tienes:

```cpp
wchar_t varaux[20] = L"1,2,3";
```

Puedes extraer los números separados por coma así:

```cpp
wchar_t* token = wcstok(varaux, L",");
while (token != NULL) {
    int valor = _wtoi(token);   // convertir a entero
    // usar valor...
    token = wcstok(NULL, L",");
}
```

---

## 📌 **1. Usar `wcstok` (la forma clásica en WinAPI)**

```cpp
wchar_t varaux[20] = L"1,2,3";

wchar_t* contexto;
wchar_t* token = wcstok(varaux, L",", &contexto);

while (token != NULL) {
    int numero = _wtoi(token);   // convierte wchar_t* → int
    // Aquí ya tienes cada número por separado

    token = wcstok(NULL, L",", &contexto);
}
```

### ✔️ Ventajas
- Funciona con `wchar_t`.
- No requiere C++ moderno.
- Perfecto para WinAPI.

---

## 📌 **2. Usar un bucle manual (si quieres control total)**

```cpp
wchar_t varaux[20] = L"1,2,3";
int numeros[10];
int idx = 0;

int acumulador = 0;

for (int i = 0; varaux[i] != L'\0'; i++) {
    if (varaux[i] == L',') {
        numeros[idx++] = acumulador;
        acumulador = 0;
    } else {
        acumulador = acumulador * 10 + (varaux[i] - L'0');
    }
}

numeros[idx++] = acumulador; // último número
```

### ✔️ Ventajas
- No modifica la cadena original.
- Muy rápido.
- Control absoluto sobre el parsing.

---

## 📌 **3. Convertir a `std::wstring` y usar C++ moderno**

```cpp
std::wstring s = L"1,2,3";
std::wstringstream ss(s);
std::wstring item;

while (std::getline(ss, item, L',')) {
    int numero = std::stoi(item);
}
```

### ✔️ Ventajas
- Código más limpio.
- Manejo automático de errores.
- Ideal si ya usas STL.

---

## 🧪 **Ejemplo completo con WinAPI (ListBox)**

```cpp
wchar_t varaux[20] = L"1,2,3";
wchar_t* contexto;
wchar_t* token = wcstok(varaux, L",", &contexto);

while (token != NULL) {
    int numero = _wtoi(token);

    wchar_t buffer[32];
    swprintf_s(buffer, 32, L"Número: %d", numero);

    SendDlgItemMessage(hWnd, IDC_LIST1, LB_ADDSTRING, 0, (LPARAM)buffer);

    token = wcstok(NULL, L",", &contexto);
}
```
